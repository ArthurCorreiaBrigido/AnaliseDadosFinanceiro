# AnaliseDadosFinanceiro

## Descrição
Este projeto de Análise de Dados em Python visa estudar as finanças de uma empresa fictícia consolidando receitas e despesas, calculando KPIs e gerando visualizações gráficas.

## Objetivo
- Limpar e organizar os dados da empresa em questão.
- Calcular seus principais KPIs
  - Total de receitas;
  - Total de despesas;
  - Margem de lucro;
  - Distribuição por componente e segmento.
- Identificar componentes e segmentos com maior e menor impacto financeiro.
- Gerar visualizações (gráficos de barras, linhas e scatter) que facilitem a interpretação dos resultados.

## Estrutura do Projeto
├── DadosFinanceiros.xlsx - Base de dados original
├── AnaliseFinanceira.ipynb - Notebook com todo o código e gráficos
├── README.md

## Tecnologias e Bibliotecas

- Python 3.x
- pandas
- numpy
- matplotlib
- seaborn
- Jupyter Notebook
